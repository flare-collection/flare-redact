LLM privacy guide

How to redact PII and secrets from LLM prompts

Replace sensitive values locally before the request leaves your application, let the model work with opaque references, and restore those references only at a trusted boundary.

By Umud Hasanli · Updated August 4, 2026 · Examples tested with Flare Redact 1.4

Short answer: create one redaction session per conversation. Redact every user, system, and tool message before the model call; keep the placeholder vault local; restore placeholders in the final response only where the original value is authorized.

Wrap an OpenAI client

npm install flare-redact openai
import OpenAI from 'openai';
import { wrapOpenAI } from 'flare-redact/llm';

const openai = wrapOpenAI(new OpenAI());

const response = await openai.chat.completions.create({
  model: 'your-model',
  messages: [{
    role: 'user',
    content: 'Email the invoice to alice@example.com'
  }]
});

The wrapper redacts complete message structures, including system text and tool-call arguments. The model receives an opaque placeholder in place of the email. When the reply repeats that placeholder, the wrapper restores the original for your trusted application.

Wrap an Anthropic client

import Anthropic from '@anthropic-ai/sdk';
import { wrapAnthropic } from 'flare-redact/llm';

const anthropic = wrapAnthropic(new Anthropic());

const response = await anthropic.messages.create({
  model: 'your-model',
  max_tokens: 300,
  messages: [{
    role: 'user',
    content: 'Summarize the account for alice@example.com'
  }]
});

The integration is local and model-independent: detection and substitution happen inside your process, before the provider request.

Use a session with any model API

A session is useful for an OpenAI-compatible provider, a local model, or your own transport. One session keeps a stable mapping for one conversation.

import { createSession } from 'flare-redact';

const session = createSession({ enable: ['phone'] });

const safePrompt = session.redact(userMessage);
const modelReply = await model.generate(safePrompt);
const appReply = session.restore(modelReply);

// Start a new vault when the conversation ends.
session.reset();

Default placeholders contain 96 random bits and do not reveal a global sequence. The vault mapping is still sensitive because it contains the originals; keep it scoped, short-lived, and out of logs.

Restore streaming replies correctly

A model can split one placeholder across several chunks. Replacing each chunk independently can miss it, so use the session stream restorer.

const restoreStream = session.stream();

for await (const chunk of modelStream) {
  render(restoreStream.push(chunk.text));
}

render(restoreStream.flush());

Separate model privacy from tool authorization

Prompt redaction prevents the model from seeing an original value. It does not automatically authorize every downstream tool to receive that value. For an agent with several tools, bind placeholder restoration to a runtime-owned tool scope.

import { createScopedToolBoundary } from 'flare-redact/tool';

const tools = createScopedToolBoundary();
const safeResult = tools.redactForModel('database', databaseResult);

// The HTTP tool cannot restore placeholders minted for the database scope.
const safeHttpCall = tools.restoreForTool('http_fetch', modelCall);

Read the MCP tool-boundary guide for the complete threat model and trusted routing pattern.

What prompt redaction does not guarantee

  • It cannot remove sensitive facts that no enabled detector recognizes.
  • Remaining context may still let a model infer information about a person or account.
  • Restoring a placeholder is an authorization decision, not only a string replacement.
  • Client-side redaction cannot protect a value that already reached your server or another service.
  • High-risk applications still need data minimization, access control, retention limits, and provider review.
Practical rule: redact before model egress, keep the vault local, and restore at the narrowest trusted destination—not automatically in every model-produced tool call.
